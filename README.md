# Alumni-Management-System 
A full-stack Alumni Management System built using React.js, Node.js, Express.js, and MongoDB. The platform connects students and alumni through networking, mentorship, events, job opportunities, chatbot assistance, and smart dashboard features with role-based authentication.

The system provides separate dashboards for students, alumni, and admins with secure role-based authentication and interactive features.

# Features 

• Secure Login and Registration  
• Role-Based Authentication  
• Student Dashboard  
• Alumni Dashboard  
• Admin Dashboard  
• AI Chatbot Assistance  
• Alumni Networking  
• Event and Announcement Management  
• Job and Internship Opportunities  
• Notifications System  
• Smart Recommendations  
• MongoDB Database Integration

# Installation and Setup

Clone the repository

```bash
git clone https://github.com/Shenbagapriyaa/Alumni-Management-System.git
```

# Navigate to the project folder

```bash
cd Alumni-Management-System
```

# Install frontend dependencies

```bash
npm install
```

# Run the frontend

```bash
npm start
```

# Frontend runs on:

```bash
http://localhost:3000
```

# Run the backend server

Open another terminal and run:

```bash
cd backend
node server.js
```

# Backend runs on:

```bash
http://localhost:5000
```
